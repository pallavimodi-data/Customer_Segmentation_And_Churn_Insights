# Customer Churn Intelligence Dashboard

An interactive Streamlit-based web application for customer churn analysis, customer segmentation, and business intelligence reporting using machine learning and data visualization techniques.

---

## Project Overview

Customer churn is one of the most critical business problems in the banking and financial services industry. This project provides an interactive analytics dashboard to help businesses identify churn patterns, analyze customer behavior, and gain actionable insights for customer retention strategies.

The dashboard enables dynamic filtering, KPI monitoring, geography-based churn analysis, customer segmentation, and drill-down exploration of high-value customers.

---

# Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/Customer-Churn-Intelligence-Dashboard.git
```

## Navigate to Project Folder

```bash
cd Customer-Churn-Intelligence-Dashboard
```

## Install Dependencies

```bash
pip install -r requirements.txt
```
## Run Streamlit Application
```bash
streamlit run Customer_Segmentation_app.py
```
